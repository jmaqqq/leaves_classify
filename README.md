本实验来源于李沐老师课程中的图像分类实践任务，采用 Kaggle 平台的 Classify Leaves 竞赛数据集，要求利用深度学习方法对不同种类的树叶图像进行分类。

数据集包含 18,353 张带标签的训练图像，共涉及 176 个树叶类别。本实验按照 8:2 的比例将数据划分为训练集和验证集，分别用于模型训练和性能评估。

## 一、实现方法

本实验使用 PyTorch 搭建并训练 ResNet-18 图像分类模型，根据任务要求将最后的全连接层调整为 176 个输出类别。

在模型训练方面，采用交叉熵损失函数（CrossEntropyLoss）和 SGD 优化器，初始学习率设置为 0.1，Batch Size 设置为 512，训练 30 个 Epoch。

为了研究不同训练策略对分类效果的影响，设计了六组对照实验：

1. Baseline：不使用数据增强，固定学习率。
2. Flip：增加随机水平翻转。
3. Aug：增加随机裁剪和随机水平翻转。
4. Baseline-Cosine：在 Baseline 基础上加入余弦退火学习率调度。
5. Flip-Cosine：水平翻转与余弦退火相结合。
6. Aug-Cosine：随机裁剪、水平翻转与余弦退火相结合。

所有实验采用相同的数据划分和随机种子（seed=42），以保证实验结果具有可比性。

## 二、实验结果

六组实验的最佳验证准确率如下：

| 实验方案 | 最佳验证准确率 |
|---|---:|
| Baseline | 77.74% |
| Flip | 73.88% |
| Aug | 79.02% |
| Baseline-Cosine | **87.63%** |
| Flip-Cosine | 86.62% |
| Aug-Cosine | 86.82% |

实验结果表明，余弦退火学习率调度在三种数据处理设置下均取得了明显的性能提升。其中，Baseline-Cosine 表现最好，最佳验证准确率达到 **87.63%**。

相比之下，单独使用随机水平翻转没有带来明显改善，而随机裁剪与水平翻转的组合也没有超过不使用数据增强的余弦退火方案。

## 三、实验改进
自己借助GoogLet并行思想和分类头设计，重新设计混合ResNet-18网络在ResNet-18 的四阶段、每阶段两个 BasicBlock 的残差骨架基础上，修改了输入特征提取模块和分类头。整体流程如下：

```text
输入 RGB 图像：3×224×224
             │
             ├─ 可学习分支：3×3 卷积 + BN + ReLU ─── 64×112×112
             │
             └─ 固定核分支：加权单通道变换
                           → Sobel / Laplacian / Gabor
                           → 1×1 卷积 + BN + ReLU ── 64×112×112
                                      │
                    两分支沿通道拼接：128×112×112
                                      ↓
                         1×1 特征融合 + SE 注意力
                                      ↓
                              最大池化下采样
                                      ↓
                         四阶段残差特征提取网络
                                      ↓
                              全局平均池化
                                      ↓
                      两层分类头：512 → 128 → 176
                                      ↓
                              176 类预测分数
```

设计目的是将边缘、轮廓和方向纹理等人工先验，与神经网络自动学习的特征结合，再通过注意力和残差网络完成特征选择与类别判别。

### 3.2 双分支混合特征提取

**（1）可学习卷积分支。** 输入 RGB 图像经过一个 3×3 卷积，输入通道为 3，输出通道为 64，步长为 2，填充为 1，随后连接 BatchNorm 和 ReLU。其输出尺寸为 **64×112×112**，卷积参数随训练更新，用于学习适合叶片分类的局部特征。

**（2）固定卷积核分支。** 这一分支首先对输入的三个通道做加权求和：

$$
X_g=0.299X_R+0.587X_G+0.114X_B.
$$

这里的输入已经经过通道标准化，所以实际实现是对标准化后的 RGB 张量进行加权，随后使用以下固定滤波器提取特征。

| 固定滤波器 | 数量 | 核尺寸 | 设计作用                                         |
| ---------- | ---: | ------ | ------------------------------------------------ |
| Sobel      |    2 | 3×3    | 提取水平、垂直方向的梯度响应                     |
| Laplacian  |    2 | 3×3    | 分别使用四邻域、八邻域形式提取二阶变化与边缘响应 |
| Gabor      |   12 | 7×7    | 提取不同方向和空间频率的纹理响应                 |

Gabor 滤波器由 **4 个方向（0°、45°、90°、135°）×3 个波长（3、4、5）**组成，高斯尺度参数为 2.0，空间纵横比参数为 0.5。每个生成的 Gabor 核先去均值，再按 L2 范数归一化。

两组固定卷积均使用步长 2，配合相应填充，得到相同的空间尺寸。4 个 3×3 滤波响应与 12 个 7×7 滤波响应拼接后形成 **16×112×112** 的特征，再通过可学习的 **1×1 卷积（16→64）+ BatchNorm + ReLU**，转换为 **64×112×112** 的输出。固定滤波核通过 `register_buffer` 注册，随模型保存并移动到相应设备，但不由优化器更新。分支内负责通道扩展的 1×1 卷积及 BatchNorm 参数仍参与训练。

### 3.3 特征融合与 SE 通道注意力

两个分支的输出沿通道维度拼接，形成 **128×112×112** 的特征。随后通过一个 **1×1 卷积（128→128）+ BatchNorm + ReLU** 进行通道混合，使固定滤波特征与可学习特征能够共同参与后续表示。

融合结果进入 SE（Squeeze-and-Excitation）通道注意力模块：先通过全局平均池化，将每个通道压缩为一个标量；再经过 **128→8→128** 的两层全连接变换，中间使用 ReLU，最后使用 Sigmoid 输出通道权重。缩减比例为 **16**。

其计算可表示为：

$$
\mathbf{s}=\sigma\!\left(W_2\operatorname{ReLU}\!\left(W_1\operatorname{GAP}(F)\right)\right),
\qquad F'_{c,h,w}=s_cF_{c,h,w}.
$$

### 3.4 残差主干

融合及注意力处理后，使用核尺寸为 3×3、步长为 2、填充为 1 的最大池化，将空间尺寸降为 56×56。后续设置四个残差阶段，每阶段包含两个 BasicBlock，总计八个残差块。

| 模块               | 核心配置                                   | 单张图像的输出尺寸 |
| ------------------ | ------------------------------------------ | ------------------ |
| Hybrid 输入模块    | 双分支、1×1 融合、SE                       | 128×112×112        |
| 最大池化           | 3×3，步长 2                                | 128×56×56          |
| 残差阶段 1         | 2 个 BasicBlock，输出 64 通道，首块步长 1  | 64×56×56           |
| 残差阶段 2         | 2 个 BasicBlock，输出 128 通道，首块步长 2 | 128×28×28          |
| 残差阶段 3         | 2 个 BasicBlock，输出 256 通道，首块步长 2 | 256×14×14          |
| 残差阶段 4         | 2 个 BasicBlock，输出 512 通道，首块步长 2 | 512×7×7            |
| 自适应全局平均池化 | 输出空间尺寸 1×1                           | 512×1×1            |
| 展平               | 转换为特征向量                             | 512                |
| 分类头             | 512→256→176                                | 176                |

每个 BasicBlock 的主分支依次包含 **3×3 卷积、BN、ReLU、3×3 卷积、BN**，随后与捷径分支相加，再经过 ReLU：

$$
Y=\operatorname{ReLU}\bigl(\mathcal{F}(X)+\mathcal{S}(X)\bigr).
$$

当输入输出通道数相同且步长为 1 时，捷径为恒等映射；当通道数或空间尺寸发生变化时，使用 **1×1 卷积 + BN** 对齐。第一阶段虽然不降低空间尺寸，但需要将通道从 128 变为 64，因此其首块同样使用投影捷径。残差连接为梯度传播提供直接路径，有助于深层网络的优化。

### 3.5 分类头

全局平均池化得到 512 维特征后，分类头采用：

```text
Linear(512, 256)
→ BatchNorm1d(256)
→ ReLU
→ Dropout(p=0.3)
→ Linear(128, 256)
```

该分类头先将特征映射到 256维，再输出 176 个类别的分数。BatchNorm 用于归一化中间特征，Dropout 在训练时以 0.3 的概率将中间激活置零，以降低对局部特征的过度依赖。

最后一层直接输出 logits，不在模型内部添加 Softmax。训练时由交叉熵损失处理 logits；预测时取分数最大的类别。需要展示类别概率时，可以额外对 logits 使用 Softmax。
### 3.6 完整训练方案

最新方案在上述结构基础上使用标签平滑交叉熵、SGD 优化器以及余弦学习率退火，主要设置如下。

| 项目             | 当前设置                                    |
| ---------------- | ------------------------------------------- |
| 模型初始化       | 从头训练，未加载预训练权重                  |
| 输入尺寸         | 3×224×224                                   |
| 批量大小         | 128                                         |
| 计划训练轮数     | 30                                          |
| 损失函数         | `CrossEntropyLoss(label_smoothing=0.05)`    |
| 优化器           | SGD                                         |
| 初始学习率       | 0.1                                         |
| 动量             | 0.9                                         |
| 权重衰减         | 0.0005                                      |
| 学习率调度       | `CosineAnnealingLR(T_max=30, eta_min=1e-6)` |
| 训练随机种子     | 42                                          |
| 最佳模型选择依据 | 验证集准确率提高时保存 `best_model.pth`     |

标签平滑将真实类别的独热目标与均匀分布混合。对类别数 \(C=176\)、平滑系数 \(\varepsilon=0.1\)，第 \(k\) 类的目标为：

$$
q_k=(1-\varepsilon)\mathbf{1}[k=y]+\frac{\varepsilon}{C},
\qquad
\mathcal{L}=-\sum_{k=1}^{C}q_k\log p_k.
$$

其作用是减弱模型对训练标签的过度置信。训练和验证调用同一个损失函数，因此当前历史文件中的 `val_loss` 也是带标签平滑的交叉熵。余弦退火在每轮结束后更新学习率，使学习率随训练推进逐步降低。

### 4.1 普通 ResNet-18 的数据增强与学习率实验

以下六组均采用普通 ResNet-18、单层分类器、无标签平滑，初始学习率为 0.1，batch size 为 512，均完成 30 轮训练。

在这批实验中，三个数据模式采用余弦退火后的最高验证准确率均高于各自固定学习率的结果；其中 `baseline + cosine` 达到 **87.63%**，是普通 ResNet-18 组的最高成绩。数据增强的效果与学习率设置有关：固定学习率下 `aug` 的成绩最高，而采用余弦退火后，`baseline` 的成绩高于 `flip` 和 `aug`。
